## 🔬 Real Hardware Run Provenance (Kaggle T4)

* **Experiment:** 4-bit QLoRA fine-tuning of `Qwen/Qwen2.5-3B-Instruct` on `data/sft_train_full.jsonl` (3,000 synthetic ChatML pairs).
* **Notebooks:** [`notebooks/notebook1.ipynb`](../notebooks/notebook1.ipynb) and [`notebooks/notebook2.ipynb`](../notebooks/notebook2.ipynb).
* **Adapter Weights:** [`models/qwen2.5_3b_bangla_kie/`](../models/qwen2.5_3b_bangla_kie/) and published to Hugging Face Hub at [`isfakturjoy/bangla-kie-qwen2.5-3b-adapter`](https://huggingface.co/isfakturjoy/bangla-kie-qwen2.5-3b-adapter).
* **Measured Evaluation on Checkpoint-188 (n=5 synthetic test docs, 62 target fields):**
  - **Base Zero-Shot Model:** 26 / 62 fields value-correct (41.9%), 62 / 64 span-valid.
  - **Fine-Tuned Model:** 26 / 62 fields value-correct (41.9%), 64 / 64 span-valid (100% schema adherence).
  - **MFS Receipt (bKash) specifically:** Improved from 7 / 12 to 9 / 12 value-correct.
